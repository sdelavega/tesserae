# Tesserae 0.1.2

A crash fix release for Tesserae, a disk-space visualiser for macOS.

## Fixes

- Scanning a disk with a folder containing many unreadable folders no longer crashes.

## Install

- **Download:** `Tesserae-0.1.2.dmg` below. Open it and drag Tesserae to Applications. The app is signed, notarized and stapled.
- **Homebrew:** `brew tap sdelavega/tap`, then `brew install --cask sdelavega/tap/tesserae`.

Requires macOS 13 Ventura or later, on Apple Silicon or Intel.

## Updates

If you already use Tesserae, choose **Tesserae → Check for Updates…** to install this release. Tesserae updates itself with [Sparkle](https://sparkle-project.org). It checks a signed feed once a day, sending only the app and macOS versions. You can turn automatic checks off in **Settings**.

## Feedback

Please [open an issue](https://github.com/sdelavega/tesserae/issues/new) for bugs, confusing numbers or ideas. For scan problems, **Scan report → Copy Diagnostics** gives the details; check it for file names you'd rather not share first.
