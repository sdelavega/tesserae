# Tesserae 0.2.2

- A Changes colour mode (⌘4) showing what grew, shrank or appeared since the previous complete scan of the same location, with links to the places that grew most. Tesserae keeps a small per-location summary of each complete scan for this comparison.
- Find Duplicate Files… (⌥⌘D): groups files of 1 MB or more with identical SHA-256 content, never downloads cloud-only files, and ignores extra hard links. Each group keeps its oldest copy unselected.
- Find Rebuildable Folders… (⌥⌘B): lists folders developer tools recreate on demand — node_modules, Xcode DerivedData and device support, Simulator caches, package manager download caches, SwiftPM .build folders, and folders marked with a CACHEDIR.TAG file.
- Saved locations under File → Saved Locations for one-click scans, and a Settings → Locations pane with a Never scan list that every scan skips and the report marks as excluded in Settings.
- Neither clean-up search deletes anything: both stage what you choose into Reclaim Space, where every protection, warning and confirmation still applies.
