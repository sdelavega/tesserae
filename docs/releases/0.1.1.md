# Tesserae 0.1.1

A small fix release for Tesserae, a disk-space visualiser for macOS.

## Fixes

- **Homebrew installation.** Updated the macOS requirement for current Homebrew versions and ensured the Tesserae tap is available before checking the release download.
- **Clearer empty states.** Reclaim Space now says “Nothing staged” when empty, and Recently compressed shows “No compressed items.” when there is no history.
- **Staging from the Inspector.** Add to Reclaim Space stages your selected items, including after the pointer leaves the map. With no selection, it stages the item you are pointing to.

## Install

- **Download:** `Tesserae-0.1.1.dmg` below. Open it and drag Tesserae to Applications. The app is signed, notarized and stapled.
- **Homebrew:** `brew tap sdelavega/tap`, then `brew install --cask sdelavega/tap/tesserae`.

Requires macOS 13 Ventura or later, on Apple Silicon or Intel.

## Updates

If you already use Tesserae 0.1.0, choose **Tesserae → Check for Updates…** to install this release. Tesserae updates itself with [Sparkle](https://sparkle-project.org). It checks a signed feed once a day, sending only the app and macOS versions. You can turn automatic checks off in **Settings**.

## Feedback

Please [open an issue](https://github.com/sdelavega/tesserae/issues/new) for bugs, confusing numbers or ideas. For scan problems, **Scan report → Copy Diagnostics** gives the details; check it for file names you'd rather not share first.
