# Tesserae 0.2.3

A safety and design release for Tesserae, a disk-space visualiser for macOS.

## Safer clean-up searches

- **Find Rebuildable Folders** only lists a `node_modules` folder when its project has a `package.json`. Folders that contain anything Tesserae couldn't read, cloud-only items or a Never scan location are listed but no longer selected for you.
- **Find Duplicate Files** checks that every copy is still unchanged before staging it. If a copy was edited after the search, Tesserae asks you to search again.
- **One copy is always kept**, however you stage: from the duplicates sheet, the map, the folder tree or the Inspector, and even when you stage a folder that contains a copy.
- Checking for a `CACHEDIR.TAG` file never downloads a cloud-only file.

## Changes and Never scan

- Changes mode (⌘4) compares a scan only with an earlier one of the same kind (full or Limited) that covered the same places: the same Never scan list and the same unreadable folders. Scans of `/Users/…` and `/System/Volumes/Data/Users/…` count as the same location.
- Changes now also reports a folder that shrank below the size Tesserae tracks.
- Scan history keeps at most 50 locations. **Settings → Locations → Clear Scan History…** removes the stored folder and file names.
- Scanning a folder on your Never scan list now explains that it's excluded instead of scanning it. Whole disks can't be added to the list.

Because the history format changed, the first scan of each location after updating starts a new comparison.

## Aether7B design

- Tesserae now follows the Aether7B v1.1 design language throughout, including Settings and every sheet: `//` section labels, opaque content cards, a 12-point minimum text size (map labels included), tabular figures for sizes and counts, and adaptive status colours with an outline and dot instead of a fill.

## Install

- **Download:** `Tesserae-0.2.3.dmg` below. Open it and drag Tesserae to Applications. The app is signed, notarized and stapled.
- **Homebrew:** `brew tap sdelavega/tap`, then `brew install --cask sdelavega/tap/tesserae`.

Requires macOS 13 Ventura or later, on Apple Silicon or Intel.

## Updates

If you already use Tesserae, choose **Tesserae → Check for Updates…** to install this release. Tesserae checks a signed feed once a day, sending only the app and macOS versions. You can turn automatic checks off in **Settings → Updates**.
