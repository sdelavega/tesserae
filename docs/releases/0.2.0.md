# Tesserae 0.2.0

A simpler, quicker release of Tesserae, a disk-space visualiser for macOS.

## What's new

- Reclaim Space now defaults to Compress for eligible items on Apple-formatted (APFS/HFS+) disks, and Move to Trash elsewhere.
- Adding items to Reclaim Space is instant; Compress shows “Estimating…” while sampling, and Archive shows “Checking…” until its inspection finishes.
- Items that were trashed, compressed or archived leave Reclaim Space automatically; untouched items stay with the reason.
- New Reported Size and Allocated columns in Folders and Largest Files help already-compressed items stand out.
- Startup-disk paths read `/Users/…` instead of `/System/Volumes/Data/Users/…`.
- Choose Simple (the default) or Detailed in **Settings → General → Detail**.
- Partial scans explain “What wasn't scanned?”, and warning bars can be dismissed with ✕.

Behind the scenes: release tooling skips version numbers whose version or build number contains `666`.

## Install

- **Download:** `Tesserae-0.2.0.dmg` below. Open it and drag Tesserae to Applications. The app is signed, notarized and stapled.
- **Homebrew:** `brew tap sdelavega/tap`, then `brew install --cask sdelavega/tap/tesserae`.

Requires macOS 13 Ventura or later, on Apple Silicon or Intel.

## Updates

If you already use Tesserae, choose **Tesserae → Check for Updates…** to install this release. Tesserae updates itself with [Sparkle](https://sparkle-project.org). It checks a signed feed once a day, sending only the app and macOS versions. You can turn automatic checks off in **Settings**.

## Feedback

Please [open an issue](https://github.com/sdelavega/tesserae/issues/new) for bugs, confusing numbers or ideas. For scan problems, **Scan report → Copy Diagnostics** gives the details; check it for file names you'd rather not share first.
