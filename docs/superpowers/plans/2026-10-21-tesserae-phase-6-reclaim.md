# Tesserae Phase 6 — Reclaim and Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the seven pre-0.1.0 changes: a volume start screen, folder colouring, folder header strips and relative paths, the Jetsam → Reclaim Space rename with a strings catalog, toolbar help, a folder-tree file list, and Compress / Archive as alternatives to Move to Trash.

**Architecture:** UI work stays in TesseraeKit (models, pure functions, testable) with thin SwiftUI/AppKit views in the app target. Compress drives a bundled, pinned applesauce helper; Archive drives `/usr/bin/tar`; both reuse the §10 staging, guard, identity, overlay and audit machinery. Rust gains two read-only FFI calls (allocated-size measurement and archive verification) and never mutates.

**Tech Stack:** Swift 6 / SwiftUI / AppKit (`NSOutlineView`), Metal, Rust (`tar`, `zip`, `xz2`, `zstd`, `sha2` crates), applesauce (GPL-3, bundled), bsdtar.

**Spec:** `docs/superpowers/specs/2026-10-18-tesserae-design.md` — §2, §8 (Colour, Labels, Folder headers and paths, Zoom, File table, Window and session), §10 (naming), §10a (all).

## Global Constraints

- macOS 13 floor; Swift strict concurrency as already configured; no new Swift packages.
- New Rust crates must pass `just deny` (licence allowlist); `--locked` everywhere.
- Every user-facing string goes through `Localizable.xcstrings` via `String(localized:)` with a translator comment (from Task 3 on; Task 3 converts existing strings).
- Text never wears a tile colour; ink is `#0b0b0b` / `#f0efec`, chosen per fill (§8 Labels).
- Rust never opens for writing, creates, renames or deletes a path; for tar.zst it only zstd-encodes between two descriptors Swift created (Ruling P6-R3). Swift never calls `removeItem`, `unlink` or `rmdir`; a file Tesserae created and must discard goes to the Trash.
- Subprocesses: `posix_spawn` with an absolute executable path, a raw-byte argv (non-UTF-8 paths survive), environment `PATH=/usr/bin:/bin` only, never a shell or Foundation `Process`. Mutation subprocesses are only `Contents/Helpers/applesauce` (`compress`/`decompress`) and `/usr/bin/tar -c`.
- applesauce is always invoked with `--verify`; arguments are explicit regular files, never directories; its exit code is never trusted.
- Archives are created with `openat(… O_CREAT | O_EXCL …)` on an identity-checked parent; never a temporary name plus rename, never an overwrite.
- No sudo, no privacy/system settings changes, no writes outside disposable disk images in tests, never touch `/Volumes/*` or iCloud. Agents strip secrets: launch with `env -u HOMEBREW_GITHUB_API_TOKEN -u OPENROUTER_API_KEY -u CLAUDE_CODE_MESSAGING_TOKEN -u GITHUB_TOKEN -u GH_TOKEN`, never print the environment.
- Never commit home paths (`just no-home-paths`), secrets, or scratch files; never `git add -f`.
- `just gate` passes at the end of every task.

## Review Focus

1. **A file changes between the manifest and Move to Trash** during Archive — expected: verification or the §10 identity re-check refuses, originals stay, the incomplete or stale archive goes to the Trash. Test in Task 11.
2. **A compressed file is later staged for Trash or Put Back** — expected: its new file ID (applesauce replaces files) is honoured, not reported as "changed since scan". Test in Task 10.
3. **Volumes appear, vanish or get renamed while the start screen is open, including an SMB share that times out on capacity** — expected: the list updates without blocking the main actor; a capacity read failure shows "Size unknown". Test in Task 4.
4. **Eight-plus root children all touching each other** — expected: assignment terminates deterministically, never two touching folders with the same slot when any other slot is free. Test in Task 5.
5. **Non-UTF-8 and control-character names in header strips, hover paths and archive entries** — expected: neutralised for display, raw bytes for filesystem work, archive verification matches byte-exact names. Tests in Tasks 6 and 8.
