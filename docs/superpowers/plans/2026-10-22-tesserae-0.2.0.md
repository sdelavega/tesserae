# Tesserae 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first round of feedback from real use: Compress as the default on Apple volumes with instant staging, plain startup-disk paths, a Simple presentation by default, dismissible banners with a partial-result explanation, and a release rule against versions containing `666`.

**Architecture:** Presentation changes live in TesseraeKit view models (pure, testable) with thin SwiftUI changes. Staging stops inspecting the filesystem; the archive inspection becomes lazy and per item. A shared `DisplayPath` formatter replaces ad-hoc path decoding for everything shown to the user. The version rule lives in `scripts/bundle-version.sh` and is called from every release path.

**Tech Stack:** Swift 6 / SwiftUI / AppKit, Bash and Python release scripts.

**Spec:** `docs/superpowers/specs/2026-10-18-tesserae-design.md` — §2, §8 "Banners, displayed paths and detail level (0.2.0)", §10a "Default action and instant staging (0.2.0)", §14 "Version numbers".

## Global Constraints

- macOS 13 floor; no new Swift packages; every user-facing string through the strings catalogs (`String(localized:)` with a comment; plural lookups via `L10n.pluralLocale`).
- Presentation settings never change what is scanned, checked, refused, logged or copied by Copy Diagnostics.
- Displayed paths are presentation only: actions, identity checks, logs, Copy Path and diagnostics keep raw bytes.
- Every §10/§10a execution-time check stays exactly as it is; only review-time waiting is removed.
- Implementer rules in `.superpowers/sdd/2026-10-21-tesserae-phase-6-reclaim/implementer-rules.md` apply (no secrets, no publishing, disposable images only, demo TSV refresh after the last code commit).

## Review Focus

1. **A staged item whose action is Archive while its inspection is still running** — expected: confirmation for that item is blocked ("Checking…"), other items are confirmable, and a late inspection result for a superseded choice is dropped. Test in Task 1.
2. **A path under `/System/Volumes/Data` that is not firmlinked (for example `/System/Volumes/Data/.Spotlight-V100` or a second Data volume)** — expected: shown unchanged; only the startup Data volume's firmlinked locations are shortened. Test in Task 3.
3. **Switching Simple/Detailed while a sheet or the scan report is open** — expected: text updates in place, nothing re-runs, no state lost. Test in Task 4.
4. **A dismissed banner when a new, different warning arises in the same session** (for example dropped tiles after a resize) — expected: the new warning shows. Test in Task 2.
5. **Version strings like `0.6.66`, `6.66.0`, `66.6.0`, `0.66.60`** — expected: refused when the string or the derived build contains `666`; `0.6.65` allowed. Test in Task 5.

### Task 1: Instant staging and Compress by default

**Files:** `apple/TesseraeKit/Reclaim/ReclaimViewModel.swift`, `Reclaim/ReclaimAction.swift`, `apple/TesseraeKit/AppModel.swift` (preparation flags), `apple/Tesserae/ReclaimView.swift`, `ConfirmReclaimSheet.swift`; tests `ReclaimViewModelTests.swift`, `ReclaimActionTests.swift`.

**Interfaces:**
- `func defaultAction(for item: ReclaimItem, volume: VolumeCapabilities, verdict: Verdict) -> ReclaimAction` — `.compress` when Compress is available and the item is not a single won't-shrink file, else `.trash`. User choices persist over defaults.
- `ReclaimViewModel` availability uses only `VolumeCapabilities` (one `statfs` per volume, cached per volume) and snapshot facts; the per-item archive inspection (`ProductionArchiveFileSystem().inspect`, open-files probe, ancestry check) runs only when an item's action is Archive, in a cancellable background task keyed by (item id, generation); results merge into that item only if still current.
- New per-item states: `estimating` (Compress estimate pending — reviewable), `checking` (Archive inspection pending — not confirmable). No global `preparing`.

### Task 3: Plain startup-disk paths

**Files:** new `apple/TesseraeKit/Labels/DisplayPath.swift`; call sites in `AppModel.swift` (window title, breadcrumb), `Interaction/Inspector.swift`, `Labels/HoverCallout.swift`, `Reclaim/ReclaimViewModel.swift`, `apple/Tesserae/ReclaimView.swift`, `ConfirmReclaimSheet.swift`, `ReclaimSummaryView.swift`, `Report/ScanReport.swift`; tests `DisplayPathTests.swift`.

**Interfaces:**
- `enum DisplayPath { static func text(_ raw: Data, startupData: Data = StartupDisk.dataRoot) -> String }` — strips the `/System/Volumes/Data` prefix only when `raw` is under the startup Data volume and its first component after the prefix is one of the firmlinked locations macOS lists in `/usr/share/firmlinks` (read at runtime; measure its format), then applies the existing label neutralisation. Anything else is neutralised unchanged.

### Task 5: Never a version with 666
